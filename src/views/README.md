# Vistas sasmlm

Una carpeta = un área de producto. Cada view habla con `src/api`, no con el backend a pelo.

| Carpeta | Fase | Contenido previsto |
| --- | --- | --- |
| `auth/` | 1–2 | Login, registro, 2FA, reset, accept invitation |
| `dashboard/` | 4 | KPIs de red |
| `team/` | 2 | Árbol y listado |
| `invitations/` | 2 | Envío y estado |
| `store/` | 3 | Productos y órdenes del dueño |
| `landing/` | 3 | Editor JSON/bloques |
| `reports/` | 4 | Cierre mensual |
| `profile/` | 1 | Perfil y seguridad |
